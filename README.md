# Burger REST API

A backend REST API developed with Java and Spring Boot as part of my Full Stack Development training at Workintech.

## Technologies

- Java
- Spring Boot
- Spring Web
- Spring Data JPA
- PostgreSQL
- Maven

## Features

- RESTful API architecture
- CRUD operations
- Database integration with PostgreSQL
- Spring Data JPA for data persistence
- Input validation
- Error handling
- Dependency Injection
- Layered application structure

## Running the Project

Clone the repository:

git clone https://github.com/seniye-sahan/FSWEB-S18D4-Maven.git

Open the project in IntelliJ IDEA or another Java IDE.

Configure your PostgreSQL database connection in the application properties.

Run the Spring Boot application.

The API runs on:

http://localhost:9000
